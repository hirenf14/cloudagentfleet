How it works

One Hub, one Worker per machine. Each machine offers Codeman, Open WebUI Computer, or both.

Hub

The dashboard you sign in to. Runs on a server or your main machine, published privately on your tailnet.

  • Dashboard and sign-in
  • List of machines
⟵ outbound only ⟶

Worker

A small service on each machine. It connects out to the Hub, so the machine never opens a port.

  • Keeps the backends running
  • Relays sessions and UIs
runs

Codeman · Open WebUI Computer

Pick one or both per machine. Your coding agents (Claude Code, Cursor, and others) run inside them.

  • Codeman: agent sessions in terminals
  • Open WebUI Computer: a full workspace

Everything your agents are doing, in one place

Built for people who run agents on more than one machine and want to check on them from anywhere.

Sessions

Start, watch, and type

Launch an agent in any approved workspace on any machine and follow its terminal live from the dashboard.

Workspaces

A full workspace, inside

Open WebUI Computer's files, editor, terminal, app previews, and agent chat open inside the dashboard, already signed in.

Machines

Windows, macOS, Linux

Codeman runs in WSL on Windows and Open WebUI Computer natively, so it works with your Windows folders.

Network

No open ports

Workers connect out to the Hub. Reach the Hub over your tailnet with Tailscale Serve; nothing faces the internet.

Setup

One guided pass

cloudagentfleet init installs what you pick, runs the services, enrolls the machine, and tells you what's next.

Fleet

Calm at any size

Search, recent sessions across machines, and a sidebar that folds what's done so busy machines stay readable.

Install

Two standalone installs. Downloads include Node.js; npm needs Node.js 22.6 or newer. Then run cloudagentfleet init.

Hub

On the server or machine that hosts the dashboard. Includes the dashboard, and a Worker if this machine should offer agents too.


          

          

            
Worker

            
On each machine whose agents you want to reach. init asks what it offers and connects it to your Hub.

            

            

          

        

      

    


    

      

        

          
Up and running in three steps

          
The dashboard walks you through the rest with a built-in Getting started checklist.

        

        

          
Start the Hub
Install the Hub and run cloudagentfleet init. It runs as a service, offers Tailscale Serve, and prints your dashboard address and password.

          
Add your machines
Install the Worker on each machine and run init. Pick Codeman, Open WebUI Computer, or both, plus any coding agents.

          
Work from anywhere
Open the dashboard, pick a machine, and start a session or open its workspace, from any device on your tailnet.

        

      

    


    

      

        

          
Private by design

          
Your machines, your network, your accounts. Read the security model.

        

        

          
Loopback Hub, tailnet access
The Hub listens on 127.0.0.1. Tailscale Serve publishes it to your tailnet only; restrict it further with ACLs.

          
Isolated machine UIs
Each machine's own UI runs on a separate origin, so it cannot use your dashboard session or call the Hub API.

          
Passwords stay on their machine
Open WebUI Computer's password never leaves its machine; the Hub only relays a session.

          
Your provider logins
Claude, Cursor, and other agents sign in on each machine themselves. Cloud Agent Fleet never handles provider credentials.
