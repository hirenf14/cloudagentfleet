# @cloudagentfleet/ui

The Cloud Agent Fleet dashboard files (`dist/public/…`: HTML, CSS, JS), on
their own.

You do not need this package to run a fleet: `@cloudagentfleet/hub` already
includes the dashboard. Use it only to
host or customise the dashboard files separately; a Hub serves this package's
files when it is installed beside it and the Hub has no bundled copy.

Only the production UI build is published; draft and source files are not.
